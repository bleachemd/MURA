# MURA — Живое наследие

Интерактивный музей казахских музыкальных инструментов: **домбра, кобыз и дауылпаз**. Посетитель сканирует QR-код рядом с экспонатом и играет движениями руки через обычную камеру телефона или компьютера. Пользователю не требуется установка приложения.

## Запуск

```sh
npm ci
npm run dev
```

Открыть http://localhost:5173. Для продакшена:

```sh
npm run build
npm run preview
```

Разместить содержимое `dist/` на статическом хостинге с **HTTPS** (например, Cloudflare Pages, Netlify или Vercel). HTTPS обязателен для доступа к камере с телефона; исключение браузеров — `localhost` на компьютере. Обычная HTTP-ссылка с локальным IP для камеры не подходит. Публичный домен в проекте не зашит: QR-коды используют текущий адрес сайта.

Прямые ссылки на экспонаты:

- `/?instrument=dombyra`
- `/?instrument=kobyz`
- `/?instrument=dauylpaz`

QR-код можно скачать как PNG для печати рядом с экспонатом. Код localhost не откроет приложение на другом устройстве: для выставки сначала разместите сайт по HTTPS и скачайте QR с опубликованного адреса.

## Законченный сценарий

1. Посетитель сканирует QR-код или выбирает инструмент в коллекции.
2. Нажимает «Включить камеру» и разрешает доступ. Это необходимый начальный шаг из-за правил разрешений камеры и звука в браузерах.
3. Показывает открытую ладонь и удерживает её 1 секунду: выступление запускается без дальнейших нажатий. Затем ненадолго опускает руку, чтобы первый жест можно было сыграть заново.
4. Повторяет последовательность из **9 жестов за 45 секунд**. Следующий жест показан поверх камеры. Каждая правильная нота добавляет 100 баллов; другой уверенно распознанный жест вычитает 25. Итог не бывает отрицательным.
5. Видит скелет кисти из 21 точки, название распознанного жеста на карточке, подсказку, прогресс мелодии, таймер и счёт. Правильный жест подсвечивается зелёным, требующий коррекции — золотистым.
6. После девяти нот или истечения времени получает результат. Можно повторить выступление открытой ладонью. Результаты и личный рекорд сохраняются в localStorage на этом устройстве.

### Три действия

| Жест | Действие |
|---|---|
| Открытая ладонь: четыре прямых пальца | Низкая нота |
| Указательный и средний прямые, безымянный и мизинец согнуты | Высокая нота |
| Кулак: четыре согнутых пальца | Ритмический удар |

Жест подтверждается после стабильного удержания примерно 320 мс. Один неподвижный жест не генерирует бесконечные ноты: нужно сменить жест либо убрать руку минимум на 350 мс. Положение большого пальца не учитывается. Поддерживаются левая и правая руки.

## Обязательный твист: режим «Ошибка»

Реализован в `src/lib/gestures.ts` и используется непосредственно в видеопотоке, а не только в инструкции.

MediaPipe определяет координаты кисти. **Собственные геометрические правила**, а не готовый классификатор жестов, сравнивают расстояние от кончика каждого пальца до запястья с расстоянием от его среднего сустава до запястья. Для каждого пальца определяется одно из трёх состояний: прямой, согнутый или промежуточный. Эти состояния сравниваются с ожидаемой комбинацией для текущей ноты.

Конкретные подсказки:

- «Выпрями указательный палец, чтобы сыграть нужный звук».
- «Согни безымянный палец, чтобы сыграть нужный звук».
- «Поднеси руку ближе: кисть слишком маленькая в кадре».
- «Перемести руку в центр кадра, чтобы все пальцы были видны».
- «Поверни ладонь к камере — сейчас виден только её край».
- При потере руки — показать кисть целиком и добавить света.

Размер кисти оценивается по расстоянию запястье–основание среднего пальца, выход за кадр — по границам координат, разворот ребром — по ширине ладони относительно её длины. Для промежуточного сгибания есть зона неопределённости: неточный жест не засчитывается и не штрафуется. Штрафуется только другой устойчиво распознанный жест.

Это эвристики для музыкальной игры, не биомеханическая или медицинская оценка. Сильные наклоны, перекрытия пальцев и слабое освещение могут снизить качество. Рекомендуется держать ладонь фронтально, пальцами вверх, целиком в кадре.

## Возможности

- Адаптивная коллекция с фильтрами, оригинальными SVG-иллюстрациями и предпрослушиванием.
- Распознавание одной руки в реальном времени, до ~15 обработанных кадров в секунду.
- Модель и WASM обслуживаются с того же сайта из `public/`: сторонний CDN для распознавания не нужен.
- Звук через Web Audio: щипковая струна Karplus–Strong, фильтрованный смычковый тембр и ударный синтез. **Цифровая интерпретация, не аутентичные записи инструментов.**
- Демо без камеры с явной маркировкой и кнопками жестов. Его результаты не учитываются в личных рекордах.
- QR-коды на отдельные инструменты, копирование ссылки и скачивание PNG.
- Корректные сообщения для запрета камеры, отсутствия камеры, занятого устройства и незашифрованного адреса.
- Камера останавливается при закрытии сессии; видео не записывается и не отправляется на сервер.
- Фокус в диалогах, закрытие Escape, поддержка reduced motion.

## Технологии и проверка

React 19, TypeScript, Vite, MediaPipe Tasks Vision 0.10.32, Web Audio API, QRCode и Lucide. Google Fonts используется только для типографики; при недоступности работает системный шрифт.

```sh
npm test       # 9 тестов распознавания и адресных подсказок
npm run build # проверка TypeScript и производственная сборка
```

Браузерная проверка с Playwright: `npm run test:e2e`. По умолчанию используется установленный Google Chrome на macOS. Для другого окружения задайте `CHROME_PATH` либо выполните `npx playwright install chromium`.

Проверяются фильтры, QR-ссылки, демо до финала, штрафы и счёт, сохранение истории, запуск MediaPipe с тестовой камерой, отсутствие горизонтального переполнения и мобильная навигация. Тестовая камера проверяет технический видеопоток и загрузку модели; качество распознавания реальной руки нужно дополнительно проверить вручную на целевых телефонах.
